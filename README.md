# Comic Reel & Retro — V2

A GitHub Pages-ready static shop for Comic Reel & Retro.

## Current build
- Posters section
- Comics section
- Product cards
- Prices
- Add-to-bag functionality
- Persistent bag using localStorage
- Responsive mobile design
- About section
- Placeholder product data ready to replace with real stock
